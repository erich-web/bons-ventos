# Brief para construção das páginas — Hotel Bons Ventos

Projeto Vite + React 19 + TypeScript + Tailwind v4 + Recharts 3 + Zustand. Idioma da interface: **português do Brasil**. Tudo roda no navegador; o motor financeiro é puro TypeScript em `src/engine`.

## Regras inegociáveis
1. **Nenhum valor financeiro hardcoded na UI.** Tudo vem de `Scenario` (premissas) ou de `Results` (calculado).
2. Toda premissa editável usa os componentes ligados ao store (`Field`, `SelectField`, `ToggleField`, `MonthRow`, `GridEditor`) ou `useScenarios().update(id, path, value)`. Nunca mutar o cenário diretamente.
3. O cenário `kind === 'excel'` é somente leitura (os componentes já desabilitam inputs).
4. Mostrar o ponto de proveniência (`ProvDot`) ao lado de premissas (os componentes `Field` etc. já fazem isso).
5. Diferenciar visualmente: premissas (inputs com ProvDot) × resultados calculados (números em `.num`, cor `text-ink`).
6. Não usar bibliotecas novas. Não alterar `src/engine/*` (se achar um bug, descreva-o no relatório final em vez de corrigir).
7. `npx tsc -b` deve passar sem erros ao final. `noUnusedLocals` está ativo: não deixe imports/variáveis sem uso.
8. Antes de terminar, tire screenshot de cada página sua com `node scripts/shot.mjs <page> /tmp/<page>.png 5173` (dev server já está rodando na porta 5173; ignore erros de console sobre fonts/ERR_TUNNEL) e **olhe a imagem** (Read) para corrigir layout quebrado, textos cortados, NaN, "—" indevidos.

## Design (siga exatamente)
- Tokens em `src/index.css`: cores `sand`, `sand-2`, `cream`, `paper`, `green`, `green-2`, `green-3`, `ocean`, `ocean-2`, `ocean-3`, `gold`, `gold-2`, `ink`, `ink-2`, `ink-3`, `line`, `rust`(negativo/alerta), `moss`. Fontes: `font-display`/classe `display`/`h1,h2,h3` = Fraunces (serif); corpo = Manrope. Números grandes usam classe `num`.
- Estética: hotelaria boutique + dashboard financeiro institucional. Fundo creme, painéis `panel` (borda fina, raio pequeno), faixas de indicadores `Ledger` (números grandes serif separados por linhas verticais) em vez de grades de cards idênticos. Sem sombras pesadas, sem gradientes decorativos, sem eyebrow em caixa alta, sem animações de entrada. Sentence case nos rótulos.
- Gráficos: cores de `CHART_COLORS` (hotel = verde, weddings = azul oceano, fnb = dourado, cost/neg = cinza/ferrugem). Use `chartAxis`, `chartTooltipStyle`, `tipFmt` (formatter tolerante). Eixos limpos, `CartesianGrid` só horizontal, `ResponsiveContainer` com altura fixa (240–320).
- Tabelas: `<table className="data">` com `th`/`td` e classe `r` para alinhar à direita, ou `DataTable`.
- Layout de página de simulador: cabeçalho (`PageHeader`), faixa `Ledger` com 4–6 KPIs da página (com `traceId` quando houver nó em `src/engine/trace.ts`), depois grid `grid-cols-1 xl:grid-cols-3`: coluna esquerda (1/3) = painéis de premissas editáveis; direita (2/3) = gráficos e tabelas de resultado. Use `Note` para avisos metodológicos (ex.: "valores de referência, não ofertas aprovadas").
- Responsivo para desktop e tablet (≥ 900px). Não precisa mobile.

## Como obter cenário e resultados
```tsx
import { useActiveScenario, useScenarios } from '../store/scenarios';
import { useResults, computeCached } from '../lib/useResults';
const s = useActiveScenario();         // Scenario ativo
const r = useResults(s);               // Results (memoizado); recalcula ao editar qualquer premissa (~10 ms)
const update = useScenarios((st) => st.update); // update(s.id, 'hotel.rateNormalYear1', [...])
```
Para simulações locais (sliders "what-if" sem gravar no cenário): `compute(withOverrides(s, [{ path, value }]))` de `src/engine/compute` e `src/engine/analysis`. Use `useMemo`.

## Contexto do negócio (para textos e notas)
Hotel boutique de 18 UH (Fase 01) + 17 UH (Fase 02 opcional) na Barrinha, Acaraú/CE, praia e kitesurf, restaurante de 95 lugares (200 com a Fase 02), beach club, destination weddings com buyout. Benchmark comercial: Saline Taíba (22 UH, ~17 casamentos/ano, 65–70% de ocupação, buyout R$76.050/diária, catering R$440/pessoa + 10%, bar R$145 + 10%, locação R$25–30k). Financiamento BNB: investimento preliminar R$23,0M (obra R$19,706M + equipamentos R$3,294M), financiamento até R$20,7M (90%), capital próprio mínimo R$2,3M, imóvel avaliado em R$6,025M, garantia preexistente exigida 80% do financiamento (R$16,56M), complementação R$10,535M. Estruturas de referência: A (R$20,7M dívida / R$2,3M equity), B (R$15M / R$8M), C (R$7,5M / R$15,5M). Sócios atuais: Karel 40%, RPE 30%, Pascoal 30%. Remuneração de garantias 1,0 / 1,5 / 2,0% a.a. (1,5% é base de negociação, não preço de mercado). Hipóteses devem ser apresentadas como hipóteses; nada deve parecer condição aprovada pelo BNB.
